 Reflection
Flexbox helped me understand how to arrange elements without relying on awkward margins or padding. The main difficulty was remembering the difference between the main axis and the cross axis. I learned that justify-content distributes items along the main axis, while align-items aligns them along the cross axis. Flex-direction changes which axis is horizontal or vertical. Flex-wrap is useful because it lets cards move onto another line when the screen becomes narrower. Overall, Flexbox makes navigation bars, card rows, and responsive layouts easier to build and maintain.
